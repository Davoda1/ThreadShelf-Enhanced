# Code-block download extensions

ThreadShelf Enhanced 1.4.2 chooses a filename from the original code-fence language, without examining or changing the code. The filename is `code-block-<number>.<extension>`. Copy and Download use the same clean code payload. Automatically formatted JSON uses the displayed JSON text; Mermaid uses the selected original or repaired source. Display-only line numbers, highlighted HTML and SVG previews are excluded.

## Coverage and maintenance

The explicit `CODE_LANGUAGE_EXTENSIONS` catalog covers all **194 registered highlighter grammars**, including Fish, plus Mermaid. The table below lists **412 accepted fence spellings**, including the app's extra aliases and an empty fence. Unknown names use `.txt`.

The registry is read from the bundled `highlight.js` dependency through `registeredCodeLanguages()`; it is not a hand-picked list of popular languages. `test/code-downloads.test.js` iterates every registered grammar and alias and every application alias. Adding a grammar without a deliberate catalog entry fails that test. Original-format overrides are in `CODE_FENCE_EXTENSIONS`.

Language names are case-insensitive. The same mapping applies to `language-js`, `lang-js`, `.js`, `{.js}`, and a fence followed by metadata such as `js title="example"`.

## Format decisions

- Original tags retain meaningful distinctions even when highlighting shares a grammar: HTML/XML/SVG, C/C++ headers, CommonJS/ES modules, JSX/TSX, INI/TOML, JSON/JSONC/JSON5, Perl modules, and Kotlin scripts.
- `dockerfile` downloads as `.dockerfile` and `makefile` as `.mk`, so both have an explicit suffix. Rename to the conventional extensionless `Dockerfile` or `Makefile` when using tools that expect those exact default names.
- WebAssembly source is text (`.wat`), not compiled `.wasm`; FANUC TP source is text (`.ls`), not a binary `.tp` program. A download never compiles the code.
- Excel highlighting describes formula text, so `excel`, `xls`, and `xlsx` save as `.txt`; a formula snippet is not an Excel workbook.
- REPL/session transcripts, profiler output, CSP header snippets, and Tagger Script snippets have deliberate `.txt` mappings. They are covered entries, not missed languages. Shell commands tagged `sh` or `shell` use `.sh`; transcripts tagged `console`, `terminal`, `shellsession`, or `shell-session` use `.txt`, matching the renderer's existing distinction.
- The shared `ls` and `ml` aliases retain their literal source suffixes. Their highlighting follows the existing registry's resolution; use the full language name to disambiguate the syntax.
- Configuration types use their text configuration suffixes. A generic `systemd` block uses `.service`; other unit kinds can be renamed when saved. `irpf90` and `cmake.in` retain compound suffixes.
- Untagged blocks and `text`, `txt`, `plain`, `plaintext`, `output`, `log`, `no-highlight`, and `nohighlight` save as `.txt`. No source is guessed from its contents.
